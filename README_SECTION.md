## Architecture & Flow Diagrams

This project includes comprehensively generated Mermaid diagrams detailing the structural integrity and data flows of the application.

- **[ProjectArchitecture.md](./ProjectArchitecture.md)**: Contains the Database Entity Relationship (ER) Diagram, Request Lifecycle, and Security/Authorization Flow.
- **[Architecture.md](./Architecture.md)**: Details the High-Level System Architecture, Frontend Component Hierarchy, Backend Layer Diagram, and the complete Repository File Tree.
- **[FlowDiagram.md](./FlowDiagram.md)**: Contains isolated flow diagrams for key modules including Authentication, Employee CRUD, Task CRUD, Notifications, Uploads, and Dashboard Analytics.

*Note: You can view these `.md` files in any Markdown viewer or IDE (like VSCode or GitHub) that supports Mermaid diagram rendering.*
